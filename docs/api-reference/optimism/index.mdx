# Optimism API overview

This section provides reference information for the Optimism JSON-RPC API.

Optimism is an optimistic layer 2 rollup chain that uses the [OP Stack](https://docs.optimism.io/stack/getting-started), 
a standardized, shared, and open-source development stack that powers Optimism and other L2 chains.

:::info See also

For more information, refer to the official [Optimism documentation](https://docs.optimism.io/).

:::

## Supported APIs

Optimism provides full compatibility with Ethereum's JSON-RPC API interface, allowing developers
to interact with Optimism using standard Ethereum tooling.

## Supported networks

DIN supports the following Optimism networks:

- Mainnet
- Sepolia testnet
