# Supported APIs

DIN provides access to multiple blockchain network APIs via Web3 gateways such as Infura. You obtain
endpoints and API keys from your chosen gateway, and call standard JSON-RPC/WebSocket APIs as usual.

DIN improves reliability and routing behind the scenes to node providers that support the networks
you need.
