# Mantle API overview

This section provides reference information for the Mantle JSON-RPC API and Debug API.

Mantle is an Ethereum layer 2 (L2) network that leverages modular architecture and optimistic rollups to deliver low fees and high performance, while maintaining Ethereum compatibility.

:::info See also

For more information, refer to the official [Mantle documentation](https://docs.mantle.xyz/).

:::

## Supported APIs

Mantle provides full compatibility with Ethereum's JSON-RPC API interface, allowing developers
to interact with Mantle using standard Ethereum tooling. Additionally, it offers Debug API methods
for advanced debugging and tracing capabilities, as well as Mantle-specific rollup methods.

## Supported networks

DIN supports the following Mantle networks:

- Mainnet
- Sepolia testnet
