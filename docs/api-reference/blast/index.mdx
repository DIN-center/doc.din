# Blast API overview

This section provides reference information for the Blast JSON-RPC API.

Blast is an Ethereum Layer 2 (L2) solution designed to bring native yield to Ether and stablecoins. It utilizes optimistic rollups to enhance scalability while maintaining compatibility with the Ethereum Virtual Machine (EVM).

:::info See also

For more information, refer to the official [Blast documentation](https://docs.blast.io/).

:::

## Supported APIs

Blast provides full compatibility with Ethereum's JSON-RPC API interface, allowing developers
to interact with Blast using standard Ethereum tooling.

## Supported networks

DIN supports the following Blast networks:

- Mainnet
- Sepolia testnet
