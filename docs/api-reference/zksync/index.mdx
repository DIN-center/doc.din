# ZKsync Era API overview

This section provides reference information for the ZKsync Era JSON-RPC API and ZKsync-specific API.

ZKsync Era is a zero-knowledge (ZK) rollup that scales Ethereum with cutting-edge ZK tech. It provides
faster, cheaper transactions while maintaining Ethereum's security model through cryptographic validity
proofs.

:::info See also

For more information, refer to the official [ZKsync Era documentation](https://docs.zksync.io/).

:::

## Supported APIs

ZKsync Era provides full compatibility with Ethereum's JSON-RPC API interface, allowing developers
to interact with ZKsync using standard Ethereum tooling. Additionally, it offers ZKsync-specific methods
for advanced features like L1/L2 messaging, batch queries, and ZK-specific functionality.

## Supported networks

DIN supports the following ZKsync networks:

- Mainnet
- Sepolia testnet
