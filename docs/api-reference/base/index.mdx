# Base API overview

This section provides reference information for the Base JSON-RPC API.

Base is an optimistic layer 2 rollup chain built by Coinbase on the MIT-licensed
[OP Stack](https://docs.optimism.io/stack/getting-started#the-op-stack-today), in collaboration with
Optimism.

:::info See also

For more information, refer to the official [Base documentation](https://docs.base.org/).

:::

## Supported APIs

Base provides full compatibility with Ethereum's JSON-RPC API interface, allowing developers
to interact with Base using standard Ethereum tooling.

## Supported networks

DIN supports the following Base networks:

- Mainnet
- Sepolia testnet
