# Arbitrum API overview

This section provides reference information for the Arbitrum JSON-RPC API.

Arbitrum is a Layer 2 (L2) optimistic rollup that inherits Ethereum-level security. Arbitrum enhances
Ethereum's capabilities by enabling high-throughput, low-cost smart contracts while maintaining
trustless security.

:::info See also

For more information, refer to the official [Arbitrum documentation](https://docs.arbitrum.io/).

:::

## Supported APIs

Arbitrum provides full compatibility with Ethereum's JSON-RPC API interface, allowing developers to
interact with Arbitrum using standard Ethereum tooling.

## Supported networks

DIN supports the following Arbitrum networks:

- Mainnet
- Sepolia testnet
