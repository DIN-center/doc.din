# `zks_estimateGasL1ToL2`

Returns an estimate of the gas required for a layer 1 (L1) to layer 2 (L2) transaction.

## Parameters

- `from`: (string) _[required]_ - Address from which the transaction is sent.
- `to`: (string) _[required]_ - Address to which the transaction is addressed.
- `data`: (string) - Data associated with the transaction.

## Response

The estimate of the gas required for a L1 to L2 transaction.

## Example

Replace `<ENDPOINT>` with an API endpoint from your DIN gateway.
