# `zks_L1ChainId`

Returns the chain ID of the underlying L1.

## Parameters

None.

## Response

The L1 chain ID.

## Example

Replace `<ENDPOINT>` with an API endpoint from your DIN gateway.

### Request

<Tabs>
  <TabItem value="curl">

  ```bash
  curl <ENDPOINT> \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{"jsonrpc": "2.0", "id": 1, "method": "zks_L1ChainId", "params": []}'
  ```

  </TabItem>
  <TabItem value="WSS">

```bash
wscat -c <ENDPOINT> -x '{"jsonrpc": "2.0", "id": 1, "method": "zks_L1ChainId", "params": []}'
```

  </TabItem>
</Tabs>

### Response

<Tabs>
  <TabItem value="JSON">

  ```json
  {
    "jsonrpc": "2.0",
    "result": "0x1",
    "id": 1
  }
  ```

  </TabItem>
</Tabs>
