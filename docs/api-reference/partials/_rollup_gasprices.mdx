# `rollup_gasPrices`

Returns the current layer 1 (L1) and layer 2 (L2) gas prices.

## Parameters

None

## Returns

Gas price object:

- `l1GasPrice`: L1 gas price fee in wei.
- `l2GasPrice`: L2 gas price fee in wei.

## Example

Replace `<ENDPOINT>` with an API endpoint from your DIN gateway.

### Request

<Tabs>
  <TabItem value="curl">

```bash
curl <ENDPOINT> \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "rollup_gasPrices", "params": [], "id": 1}'
```

  </TabItem>
  <TabItem value="WSS">

```bash
wscat -c <ENDPOINT> -x '{"jsonrpc": "2.0", "method": "rollup_gasPrices", "params": [], "id": 1}'
```

  </TabItem>
</Tabs>
