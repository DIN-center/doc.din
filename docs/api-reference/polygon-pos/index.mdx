# Polygon PoS API overview

This section provides reference information for the Polygon PoS JSON-RPC API.

Polygon PoS (Proof of Stake) is a scaling solution for Ethereum that achieves scale by utilizing
sidechains for off-chain computation while ensuring asset security using the Plasma framework and a
decentralized network of Proof of Stake (PoS) validators.

:::info See also

For more information, refer to the official [Polygon documentation](https://docs.polygon.technology/).

:::

## Supported APIs

Polygon PoS provides full compatibility with Ethereum's JSON-RPC API interface, along with additional
Bor-specific methods for interacting with Polygon's consensus layer.

## Supported networks

DIN supports the following Polygon PoS networks:

- Mainnet
- Amoy testnet
