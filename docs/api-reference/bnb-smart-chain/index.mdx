# BNB Smart Chain API overview

This section provides reference information for the BNB Smart Chain (BSC) JSON-RPC API methods.

BSC is a self-sovereign blockchain with elected validators running a Proof of Staked
Authority (PoSA) consensus protocol. It is EVM-compatible and supports existing Ethereum tooling.

:::info See also

For more information, refer to the official [BSC documentation](https://docs.bnbchain.org/bnb-smart-chain/).

:::

## Supported APIs

BSC provides full compatibility with Ethereum's JSON-RPC API interface, allowing developers
to interact with BSC using standard Ethereum tooling.

## Supported networks

DIN supports the following BNB Smart Chain networks:

- Mainnet
- Testnet
