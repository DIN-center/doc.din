Solana provides a high-performance network that is utilized for a range of use cases, including
finance, NFTs, payments, and gaming.

Solana operates as a single global state machine and is open and interoperable.

:::info See also
- See the [official Solana documentation](https://solana.com/docs) for more information.
:::

## Supported APIs

DIN supports the following Solana APIs:

- **Core JSON-RPC API**: These are the core Solana JSON-RPC methods for interacting with
    the Solana network.
- **Digital Asset Standard API (DAS)**: The DAS API provides an interface for interacting with
    digital assets such as fungible tokens, regular NFTs, and compressed NFTs.

## Supported networks

DIN supports the following Solana networks:

- Mainnet
- Devnet
